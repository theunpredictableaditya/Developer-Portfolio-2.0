## What this is
A modern, interactive single-page portfolio built with React + TypeScript and styled with SCSS. It showcases projects and the author’s journey using small, animated UI components (e.g., an experimental cursor blob and a navigation bar with GSAP-driven motion).

### Stack
- Language(s): TypeScript, SCSS, HTML
- Framework / runtime: React (Vite + React 19)
- Notable libraries:
  - gsap / @gsap/react — runtime animations
  - sass — SCSS compilation
  - Vite — dev server and build tooling
  - TypeScript — static typing and build
